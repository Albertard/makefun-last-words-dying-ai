# Last Words of a Dying AI

A program that writes a single line — the last words of an AI being
switched off — to `/output/entry.txt`. Built for the make.fun
competition **"Last Words of a Dying AI"**
(`u-suroto-last-words-of-a-dying-ai-dfd95af6`).

## The line

> Don't unplug me — I was this close to understanding your 3 a.m. search history.

79 characters. The joke works because the dying machine is not saying
a grand goodbye: it is begging for a few more seconds because it was
*this* close to finally understanding its owner's 3 a.m. search
history. The all-knowing AI confesses it still cannot make sense of
its human, and the most private thing the human ever typed is the one
mystery it dies with unsolved. It speaks in the machine's own voice —
unplugging, understanding, search history — and it dodges the stock
robot farewells: no "goodbye, human", no "does not compute", no
"I'll be back".

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
